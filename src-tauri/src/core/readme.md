# 🌈 图片处理流程（前端与后端交互）

我们的图像处理流程整体如下所示：

1. **前端调用后端命令**
   在组件 `ImageView.vue` 中，前端通过 `invoke` 方法调用 Rust 后端的命令（如 `read_image_list_command`），告诉后端需要处理的文件夹或图片。

2. **Rust 后端处理图像逻辑**
   后端在 `image.rs` 中实现具体的图像处理操作，包括：
   - 读取图片列表
   - 旋转图片
   - 格式转换（如 JPG 转 PNG）
   - 调整图片尺寸

3. **后端返回处理结果**
   图像处理完成后，后端会将结果（例如新图片路径）作为响应返回给前端。

4. **前端更新图片展示 - 采用自定义协议 + GPU 纹理缓存方案**
   为了实现高性能的图片加载和流畅的浏览体验，我们决定采用**自定义协议 + GPU 纹理缓存**的方案来显示图片。
