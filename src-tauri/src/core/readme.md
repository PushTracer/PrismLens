# 🌈 图片处理流程（前端与后端交互）

我们的图像处理流程整体如下所示：

1. **前端调用后端命令**
   在组件 `ImageView.vue` 中，前端通过 `invoke` 方法调用 Rust 后端的命令（如 `get_directory_images_command`），告诉后端需要处理的文件夹或图片。

2. **Rust 后端处理图像逻辑**
   后端在 `image.rs` 中实现具体的图像处理操作，包括：
   - 读取图片列表
   - 格式转换（如 JPG 转 PNG）
   - 调整图片尺寸

   旋转、缩放、拖拽属于**纯视图变换**，由前端 CSS transform 完成，不经过后端、不写磁盘。

3. **后端返回处理结果**
   需要写盘的操作（格式转换、尺寸调整）会先弹出"另存为"对话框，后端只把结果写入用户显式选择的路径，不生成额外副本。

4. **前端更新图片展示 - 采用官方 asset 协议**
   为了实现高性能的图片加载和流畅的浏览体验，图片通过 Tauri 官方 asset 协议直接读取本地文件，无需经过 IPC 传输字节。
   前端拿到图片路径后，将 `<img>` 标签的 `src` 设置为 `convertFileSrc` 生成的协议路径：

   ```html
    在开发模式下，URL 格式为： http://asset.localhost/{encoded_path}

    在生产模式下，URL 格式为： asset://{encoded_path}

   ```

   这样，前端就可以通过 `asset` 协议来访问图片资源，而无需进行额外的网络请求。
