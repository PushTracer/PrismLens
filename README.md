# PrismLens - 现代化的图片查看工具

## 项目简介

PrismLens是一款基于Tauri + Vue3 + TypeScript开发的现代化图片查看工具。它不仅提供了强大的图片查看和处理功能，还计划集成社交分享和AI增强特性，致力于打造一个高性能、易用性强的图片管理工具。像棱镜镜头一样，不仅能清晰展现图片的每一个细节，更能展现图片的多彩视角。

## 核心特性

### 1. 图片基础功能

- 🖼️ 多格式图片查看和浏览
- 🔄 基础图片操作
  - 旋转
  - 缩放
  - 拖拽
- 🎨 图片格式转换
- ✂️ 图片裁剪

### 2. 社交分享功能

- 📱 QQ分享集成
- 🌐 预留其他社交平台分享接口

### 3. AI增强功能（规划中）

- 🤖 智能图片识别
- ⭐ AI图片评分
- 🏷️ 智能标签系统
